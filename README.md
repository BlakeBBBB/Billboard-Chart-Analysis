# Billboard Chart Analysis

Status: In progress

A learning project using SQL Server, Excel, and Power BI to explore
Billboard chart performance.

## Questions

- Which artists have the strongest chart performance?
- Which genres perform best?
- How does performance differ across chart-debut decades?

## Progress

- Imported the dataset into SQL Server.
- Investigated repeated song IDs and conflicting records.
- Created a separate cleaned table with one record per song ID.
- Began exploring performer credits and collaborations.

## Limitations

Repeated song IDs were reduced using peak position, chart duration,
and Spotify popularity as selection criteria. Conflicting records
have not been independently verified.

Individual artist credits are still being prepared. Current performer
summaries treat each collaboration credit as a separate act.

## Learning approach

This project includes independent practice and AI-assisted guidance.
I am learning to explain, test, and improve the queries as I progress.
